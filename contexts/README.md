# 上下文（Contexts）

从实践对话中提取的**场景上下文**记录。与 loops（循环范式）互补：loop 记录可复用的操作循环，context 记录某一类任务的完整场景——适用场景、命名约定、标准流程与注意事项。

## 维护规范

1. **从实践提取** — 内容来自真实完成的初始化/维护实践，不是凭空设计
2. **脱敏开源** — 仓库公开，不写入未公开的内部信息、个人数据与敏感细节
3. **与事实一致** — 命名、路径、流程必须与当前仓库结构对齐，随实践更新
